Employee Management System

About the Project

The Employee Management System is a web-based application developed using Python and Flask to manage employee information efficiently. It allows users to add, view, search, update, and delete employee records.

Technologies Used

- Python
- Flask
- SQLAlchemy
- SQLite
- HTML
- CSS
- Bootstrap (if used)

Features

- Employee Dashboard
- Add New Employees
- View Employee Details
- Search Employee Records
- Edit Employee Information
- Delete Employee Records
- Department Management

Project Structure

- "app.py" – Main application file
- "templates/" – HTML templates
- "static/" – CSS and static files
- "instance/" – Database storage

How to Run the Project

1. Clone the repository.
2. Install the required packages:
   "pip install -r requirements.txt"
3. Run the application:
   "python app.py"
4. Open the browser and visit:
   "http://127.0.0.1:5000/"
